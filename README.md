# Indian Wedding Invitation

A JavaScript-based React landing page built with Vite and Tailwind CSS.

## Local development

**Prerequisites:** Node.js 18+

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Open `http://localhost:3000`

## Build / Preview

- Build production output: `npm run build`
- Preview the production build: `npm run preview`

## Notes

- This project is now JavaScript-only and does not require TypeScript tooling.
- Temporary build artifacts should not be committed.
